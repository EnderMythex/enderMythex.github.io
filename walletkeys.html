Wallet Keys

Convert a wallet key between a Phantom base58 secret and the [..64 bytes..] Solana keyfile format, and generate brand-new BIP39 keypairs — all in your browser, keys never leave the tab.

🔒 100% client-side — the base58 codec runs in your browser, nothing is ever sent anywhere. A base58 secret / byte array grants full control of the wallet's funds: only paste keys you own, and never share the output.
Decode — base58 key → byte array (JSON)
Same output as the Node bs58.decode snippet: a Phantom base58 secret key becomes the [..64 bytes..] JSON array a Solana CLI keyfile uses.
Encode — byte array (JSON) → base58 key
The reverse: paste a [..64 bytes..] array (e.g. a Solana CLI keyfile) and get the base58 secret key to import into Phantom.
Generate a new wallet (BIP39 · m/44'/501'/0'/0')
Create a brand-new seed phrase and its Solana keypair, entirely offline in your browser (same derivation Phantom uses). ⚠ Anyone with the phrase or secret key owns the wallet — save it safely, never share it.
