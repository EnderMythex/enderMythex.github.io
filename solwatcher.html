Data from DexScreener (keyless, reliable CORS) — real market cap, liquidity and price. Optionally add GeckoTerminal pages for extra breadth (it can be rate-limited and log CORS errors, so it's off by default). Only genuine pump.fun coins are shown (mint ends in pump) — PumpSwap pools for tokens launched elsewhere (e.g. Meteora "Virtual Curve") are excluded. "Graduated" = pump.fun tokens that filled their bonding curve and migrated to PumpSwap. GMGN can't be used here — it blocks every browser request behind a Cloudflare challenge (an API key wouldn't help; it has no official keyed API). Add an optional Birdeye key above to overlay live, higher-rate market data using your own quota.
