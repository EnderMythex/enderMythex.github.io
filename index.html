Solana · Live feed
SolWatcher
A live board of pump.fun graduates — memecoins that migrated off the bonding curve to PumpSwap and now trade above a market-cap threshold you set (default $1M). Sort by market cap, 24h volume, gainers or newest migration, with prices, 5m/1h/24h moves and quick links. Auto-refreshes.
→ solwatcher.html
Solana · CPU Workers
Vanity Address
Generate Solana keypairs matching a custom prefix and/or suffix, entirely in your browser with multi-threaded Web Workers (tweetnacl Ed25519). Filter by exact case, ignore case, or force upper/lower. Live log shows near-miss progress. Private keys are never sent anywhere.
→ vanity.html
Solana · Phantom
SOL Wrapper
Connect Phantom to wrap native SOL into wSOL and unwrap it back with one click — entirely client-side. Builds the associated-token-account, SystemProgram transfer and SyncNative instructions in-browser; unwrap closes the account and returns all wrapped SOL plus rent.
→ solwrapper.html
Solana · Key codec
Wallet Keys
Convert a wallet key between a Phantom base58 secret and the [..64 bytes..] JSON array a Solana CLI keyfile uses — decode and encode both ways with a self-contained base58 codec. Shows the derived public key. Keys never leave your browser.
→ walletkeys.html

Ethereum · WebGPU testing
ETH Miner
Mine the HASH token directly in your browser using WebGPU compute shaders (keccak256). Auto-detects your GPU and tunes workgroup / pipeline settings. Supports GPU-only, CPU-only, or both simultaneously. Connect any EIP-1193 wallet (MetaMask, Brave, Phantom) or run a benchmark without a wallet.
→ eth_miner.html
Solana · WebGPU testing
Solana Miner
Mine your custom Solana memecoin directly in your browser. Uses WebGPU compute shaders or multi-threaded CPU workers to solve PoW hash challenges. Connect Phantom wallet, configure your Program ID, Mint Address, and PDA, and start mining.
→ sol_miner.html
