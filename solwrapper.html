Wrapping moves native SOL into your associated wSOL token account (So1111…1112). Unwrapping closes that account and returns all wrapped SOL plus the rent back to your wallet.

Same output as the Node bs58.decode snippet: a Phantom base58 secret key becomes the [..64 bytes..] JSON array a Solana CLI keyfile uses. Runs fully in your browser — nothing is sent anywhere.

The reverse: paste a [..64 bytes..] array (e.g. a Solana CLI keyfile) and get the base58 secret key to import into Phantom.
⚠ These key tools are for your own wallets. A base58 secret / byte array grants full control of the funds — never paste a key you don't own and never share the output.
